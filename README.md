# MFONS
Система методологических правил, логических инструментов и процедур верификации, для нейросетей исключающих галлюцинацию и формирование необоснованных ответов. Система опирается на синтез диалектической, формальной и математической логик + 13 дополнительных логик, психолого-педагогических концепций (Выготского, Лурии, Ильенкова).
